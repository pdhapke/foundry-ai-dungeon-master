## Installed rules API evidence

`Data/Data/systems/dnd5e/dnd5e.mjs` provides AttackActivity.rollAttack(config, dialog, message) at line 21441, returning D20Roll[] or null; native D20Roll.isCritical/isFumble expose system critical/failure rules. System attack presentation at line 86354 derives miss from critical/fumble/total and target AC. Damage rolling uses activity.rollDamage(config, dialog, message), native DamageRoll.isCritical and the system's damage configuration. Neither the attack bonus nor critical damage should be rebuilt by this integration.

Attack rolling itself can update last-use flags and consume/delete ammunition or thrown quantity (lines 21535–21606). Activity.use independently owns configured action/resource/spell-slot consumption (around line 17950). Calling rollAttack alone therefore does not universally mean all activation resources were consumed. Unsupported consumption and genuine choices must stop rather than silently use free resources.

Actor.applyDamage at line 43218 calls calculateDamage internally. calculateDamage at line 43288 accepts typed damage descriptions with properties, applies native immunity/resistance/vulnerability and modifications, and can return false through hooks. applyDamage consumes temporary HP before HP and can return unchanged after a cancellation hook. Provenance is passed to actor.update only through options.origin.getFlag('dnd5e', 'context'); arbitrary options are not automatically propagated. A returned Actor alone cannot distinguish cancelled application from successful zero damage, so native hook evidence and authoritative final state are required.
